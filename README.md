# 📝 QuickNotes

A simple and clean **note-taking web application** built using **Flask and SQLite**.

QuickNotes allows users to register, log in, create notes, view saved notes, and delete notes through a simple web interface. This project was built to understand backend development, database integration, routing, and full-stack web development using Python.

---

# 🚀 Features

- ✅ User registration
- ✅ User login system
- ✅ Create and save notes
- ✅ View all saved notes
- ✅ Delete notes
- ✅ SQLite database integration
- ✅ Flask backend
- ✅ HTML/CSS frontend
- ✅ Jinja2 template rendering

# ⚙️ Installation & Setup

Follow these steps to run QuickNotes locally.

## 1. Clone the repository

```bash
git clone https://github.com/yourusername/QuickNotes.git
```

## 2. Open the project folder

```bash
cd QuickNotes
```

## 3. Install Flask

```bash
pip install flask
```

## 4. Run the application

```bash
python app.py
```

## 5. Open in browser

```
http://127.0.0.1:5000
```
